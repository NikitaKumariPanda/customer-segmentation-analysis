
# Customer Segmentation Dashboard

An interactive Streamlit app for exploring customer data, visualizing distributions, correlations, and performing clustering with **KMeans** and **t-SNE**.

---

## 🚀 Features
- Upload your own CSV dataset
- Explore dataset preview, shape, and summary statistics
- Visualize categorical distributions with Seaborn
- Correlation heatmap for feature relationships
- Dimensionality reduction using **t-SNE**
- Elbow method for optimal cluster selection
- KMeans clustering visualization

---
